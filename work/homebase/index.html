01

The problem

Our family ran on a commercial to-do app. It couldn't feed our kitchen wall display, didn't know about meals or medications, and kept our lists on someone else's server.

I wanted one place for tasks, shopping, chores, the meal plan and medication doses, shared by the household and shown on the wall, and a way to build it quickly without giving up on quality.

02

What I built

A full task managerLists in folders, sections, labels, saved filters, subtasks, repeats, reminders, comments, Today, Upcoming, Inbox, search and live updates.
A drop-in for TodoistA Todoist import and a Todoist-compatible API, so our existing lists and habits moved over instead of starting from scratch.
Meals and medicationsA meal library and weekly plan, freezer stock, groceries generated from the plan, and medication doses with history, refills and alerts.
On the kitchen wallPlugins for the Home Screens wall display show tasks, meals and medication doses, through a separate wall API.
03

How it works

The app itself is a straightforward three-tier system. What is unusual is how the screens get built: each one is a small step whose test is written first, and a local AI model writes the code until that test passes.

04

Key decisions

  1. The test is the specEvery step ships with its test, proven against a working implementation before it is handed over. The model may never edit the test, so a passing step means the screen really does what was asked.
  2. Mistakes become rulesEach new kind of mistake the model makes becomes one line in the conventions file, so it does not make it again.
  3. Compatible on day oneSpeaking the Todoist API meant imports, scripts and habits carried over, instead of asking the family to start from scratch.
  4. Walls get their own keysEach wall display authenticates with its own key against a separate wall API, not with a family member's login.
  5. Boring to runOne Docker Compose file on a home server, a health check, and daily backups kept for two weeks, with restore steps written down.
05

Where it stands

Today

In daily use by our household on phones, laptops and the wall. The server has 66 tests across 14 files.

Next

More wall plugins and the remaining screens, one tested step at a time.
