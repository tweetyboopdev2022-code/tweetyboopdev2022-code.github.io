Homebase

Full-stack · self-hosted
Kotlin, Ktor, PostgreSQL
React, TypeScript, Tailwind

Our household's own Todoist-style task app: lists of every kind, shared between family members, on phones, laptops and the kitchen wall display. It runs on a home server.

  • Kotlin and Ktor API over PostgreSQL, with a React and TypeScript web app.
  • Feeds the wall display through its own plugins for tasks, the meal plan and medication doses, authenticated with per-device wall keys.
  • Built test-first in small steps: each step ships with its test as the spec, and a local AI model implements the screen against it. About 100 test files keep that loop honest.

Robin's Voice

Mobile + API · in development
Expo, React Native
Rails 8, PostgreSQL, ActionCable

A communication and care-coordination app for adults with severe non-verbal autism and the many caregivers around them. The person being cared for uses a tablet with picture buttons and a body map to say what they need or where it hurts; parents, nurses and educators get it in real time on their phones.

  • Multi-tenant by household, so one caregiver can belong to several care teams with different roles and permissions.
  • Real-time signals over WebSockets with a pending, acknowledged, resolved flow, plus medication schedules, intake limits, vitals and equipment logs.
  • Bilingual French and English, built for Quebec's privacy law (Loi 25), with sensitive fields encrypted at rest. CI runs on both the API and the app.

Standby generator monitor

Client project · mobile + IoT
Expo, React Native, Firebase
ESP32 firmware (PlatformIO)

A mobile app for an electrical contractor's customers to watch their whole-house standby generator and start or stop it remotely, plus the firmware for the small device that connects to the generator.

  • ESP32 firmware talks to Firestore over plain REST, reads run state and fault signals from the generator controller's wiring harness, and drives a hold-based start signal.
  • Commands are confirmed by sensors, not by the relay firing: pending, acknowledged, then completed only when the engine is actually running.
  • Kept on Firebase's free tier by replacing cloud functions with a scheduled sweep script for alerts, offline detection and push notifications. Security rules are covered by 60+ tests.

Fieldbook

Professional work · mobile
React Native, TypeScript
WatermelonDB, Redux Toolkit

A production offline-first field app built at work, shown here with its name and branding changed. Crews fill in forms and records with no signal, and everything syncs when they're back online.

  • Clean Architecture per feature module (domain, data, presentation) with dependency injection and branded ID types.
  • Local-first data in WatermelonDB on SQLite, with a sync service that catches up when the device is back online.
  • Detox end-to-end tests, Sentry and Datadog monitoring, bilingual French and English.
